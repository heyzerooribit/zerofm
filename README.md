# ZeroFM

Internet radio site. Pages: index (home + Zero Cards), listen, schedule, shows, djs, about, contact.

## Put it on GitHub Pages
1. Create a repo (for example `zerofm`) and upload everything in this folder to the repo root.
2. Repo Settings > Pages > Source: Deploy from a branch > `main` / root > Save.
3. Your site appears at `https://YOUR-USERNAME.github.io/zerofm/`.

## Edit
- Shows, schedule and DJs: arrays at the top of `site.js`.
- Live stream: set `STREAM_URL` in `site.js`.
- Cards: `cards-data.js` and the `cards/` images.

## Install as an app
The site is an installable web app (PWA) once it is on GitHub Pages.
- iPhone: open in Safari > Share > Add to Home Screen.
- Android: open in Chrome > menu > Install app.
- Desktop Chrome or Edge: click the install icon in the address bar.
